# 输入框边缘双像素吉祥物（Pixel Edge Mascots）

## 1. 设计精髓（为什么可爱且耐玩）
- **极简低多边形像素轮廓（`crispEdges`）**：珊瑚色方体小蟹（`#D97856`）+ 薰衣草紫像素小猫（`#9B87F5`）+ 迷你盆栽仙人掌，用不到 20 个像素块勾勒出超高辨识度，在深色 UI 边缘点缀出温暖的生命力而不喧宾夺主。
- **把容器上沿变成“微型舞台”**：两只小吉祥物脚踩在输入框或卡片的 `top: 0` 边线上自由散步、对视聊天、绕开仙人掌，完全不遮挡正文输入区域。
- **高反馈物理触感**：每一次点击都有挤压拉伸（Squash & Stretch）+ 像素粒子反馈；拖拽时有阻尼摆锤倾斜与悬空蹬腿；松手带真实重力抛物线与弹跳落轨。

## 2. 完整交互矩阵
1. **每次点击轮换 7 种动作**（两只宠物各自独立计数，绝不单调）：
   - `happy_jump`：蓄力高跳 + 像素金星四散
   - `backflip`：360° 空中后空翻 + 落地像素烟尘
   - `dance`：节奏左右摇摆 + 浮动像素音符
   - `blush`：害羞脸红 + 漂浮像素爱心
   - `nap`：趴平打盹（`- -` 眯眼 + 像素 `Z` 气泡），再点立刻惊醒跳起
   - `dash`：沿边框极速冲刺急刹 + 像素拖尾
   - `highfive`：呼叫另一只跑过来击掌庆祝
2. **自由拖拽 & 物理抛掷**：
   - 按住任意一只拖拽离开边框：身体随拖拽速度产生摆锤倾斜、四条小腿悬空乱蹬、眼睛变成惊讶 `O O`。
   - **拖到另一只头顶松手 → 叠罗汉（Piggyback Stack）**：上面那只稳稳站在下面那只头顶一起走！点击或拖开即可解除。
   - **拖到仙人掌附近松手 → 扎脚弹跳**：弹出像素 `!` 感叹号并向旁边弹开。
   - **甩出去松手**：带惯性抛出、重力下落并在上边框弹跳落地，偏离边界会自动小跑回舞台。
3. **环境与输入联动**：
   - **像素眼神追随**：鼠标靠近时，两只小眼睛里的瞳孔微移看向指针。
   - **打字节拍响应**：在下方输入框敲字时，两只吉祥物同步随着按键轻轻点头蹦跶。
   - **点击仙人掌**：花苞短暂盛开并冒出像素微光。
   - **撒零食竞速**：点击「撒零食」在边框随机掉落像素小饼干，两只宠物立刻冲刺抢吃，吃掉后爆出爱心和碎屑粒子！

## 3. 适用场景
- AI 聊天输入框顶部装饰（Antigravity / IDE / Agent 控制台）
- 个人博客、作品集、工具类 Web App 的卡片边缘彩蛋
- 空状态（Empty State）或加载等待时的陪伴型微交互

## 4. 复用忌讳（Anti-patterns）
- 切忌使用模糊抗锯齿缩放像素图：务必保持 `shape-rendering="crispEdges"` 和整数倍视觉比例。
- 切忌让吉祥物拦截输入框内的点击：舞台容器 `pointer-events: none`，仅对吉祥物、仙人掌和粒子里的可交互元素开启 `pointer-events: auto`。
- 切忌在严肃数据表格/金融表单页面滥用，最适合高频陪伴型工具与创意开发界面。
