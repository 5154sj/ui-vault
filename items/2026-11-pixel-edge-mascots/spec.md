# 输入框边缘双像素吉祥物（Q弹微像素互动版）

## 1. 设计精髓（Q弹果冻手感 + 纯像素美学）
- **二阶欠阻尼弹簧体积守恒形变（真·Q弹引擎）**：不再使用僵硬的线性缩放，而是为每个吉祥物（以及仙人掌和粒子）驱动独立的二阶弹簧 `squash`（`scaleX = 1 + s, scaleY = 1 - s`）与旋转弹簧 `rot`。点击、起跳、拎起、落地、叠罗汉、甚至打字时都会呈现“麻薯/果冻”般的过冲回弹，同时**落地一触即稳**，只做果冻压缩回弹而不再连环乱抖。
- **精细 `28×24` 微像素颗粒 + 全像素风粒子**：零文字气泡、零圆滑渐变特效，所有点击与互动粒子（像素星爆、像素冲击环、像素爱心、像素音符、像素 Zzz、像素饼干碎屑）全部以 `crispEdges` 像素块绘制，并带有弹簧 Q弹弹出缩回曲线。
- **极低自动乱跑 + 丰富待机持续动作**：宠物默认稳稳待在原位（极少自主走动），待机超过 ~7.5 秒后自动进入持续待机表演（软绵绵呼吸打盹飘 `Zzz`、原地 Q弹踩奶蹦跶、好奇歪头张望、或两只对视冒爱心），直到被互动唤醒。

## 2. 完整交互矩阵
1. **每次点击轮换 7 种 Q弹像素动作**：
   - 蓄力果冻高跳 + 像素星环爆发
   - 360° 软弹后空翻 + 像素落尘
   - 节奏 Q弹摇摆舞 + 像素音符
   - 害羞果冻颤抖脸红 + 像素爱心
   - 趴平软糯打盹（持续呼吸 + `Zzz`，再点 Q弹惊醒）
   - 边框冲刺急刹前倾回弹
   - 呼叫伙伴贴贴击掌
2. **拎起拖拽 + 轻松叠罗汉**：
   - 拎起瞬间有纵向拉伸果冻感，拖拽时随速度软弹倾斜；
   - **拖到另一只头顶附近**会出现微弱像素落点提示箭头，松手即稳稳**叠罗汉**，下面那只被压出明显的双层麻薯共振回弹！
   - 叠罗汉状态下点下面那只，上下两只会产生错峰波浪式联动 Q弹！
3. **全元素 Q弹联动**：
   - 点击角落仙人掌：仙人掌本身也会果冻摇晃并喷出像素花瓣星光；宠物碰到仙人掌会弹跳躲开。
   - 撒零食竞速：像素饼干 Q弹落到边框，双宠冲刺抢吃并爆出像素碎屑与爱心。
   - 输入框打字：每敲一字，双宠同步做轻柔 Q弹跟拍点头。

## 3. 复用忌讳（Anti-patterns）
- 保持 `shape-rendering="crispEdges"` 确保像素边缘锐利；
- 严禁在宠物头上叠加文字气泡，全部情绪由像素表情 + 像素粒子传达；
- 弹簧阻尼系数建议保持在 `0.70–0.78` 之间：低于 `0.62` 会显得僵硬，高于 `0.85` 会抖个不停。
